# Data card

All observations are generated by `make_data(seed=42)`. There are no client,
employer or personal records. Each of 6,000 rows represents one fictional
customer with tenure, weekly sessions, support tickets, fee, monthly-contract
indicator and recent usage change. The outcome is a Bernoulli draw from the
documented logistic simulation. Features precede the simulated outcome.

Rows are ordered by an abstract cohort time, which changes usage and baseline
risk slightly. IDs and time are not model features. There are no repeated
customers. The generator is MIT licensed with the rest of this repository.
Do not interpret this as a sample of real customer behaviour.
